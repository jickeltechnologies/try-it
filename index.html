Try it: build your first web page

Read the steps, change the code on the left, and watch your page update on the right. You can’t break anything. Press Reset to start over.

Your challenge

  1. Change the heading Hello, world! to your own name or message
  2. Add a paragraph with <p>Your text</p>
  3. Add a link: <a href="https://example.com">Click me</a>
  4. Change the heading color: <style>h1{color:tomato}</style>

Tip: anything between < and > is a tag. Tags tell the browser what each part of the page is.
